# Portfolio Website

A responsive personal portfolio website built with HTML, CSS, JavaScript, and jQuery for a web development assignment.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Elements**: JavaScript-powered features for enhanced user experience
- **All Required Sections**: Home, About Me, Skills, Projects, and Contact

## Sections

### Home Page
- Hero section with introduction
- Call-to-action buttons
- Social media links
- Animated typing effect

### About Me
- Personal introduction
- Background information
- Contact details

### Skills
- Frontend development skills
- Tools and technologies
- Animated skill bars

### Projects
- Project showcase
- Technology tags
- Demo and source links

### Contact
- Contact form with validation
- Contact information
- Social media links
